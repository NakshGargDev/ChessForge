# ChessForge ♟️

A chess game built from scratch with JavaScript.

## Features

- Legal move validation
- Check and checkmate
- Castling
- En passant
- Pawn promotion
- Captures
- Turn handling
- Undo system

## Play

ChessForge is available as a live web app on Vercel.
https://forge-chess.vercel.app

## Version

Current version: **v1.0.0**
